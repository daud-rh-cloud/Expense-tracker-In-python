# Expense-tracker-In-python
A small command-line expense tracker built while learning Python.

## What it does

- Add expenses with a name and price
- View all expenses
- View your total spend
- Quit anytime

## How to run

```bash
python learn.py
```

## What I learned

- While loops and for loops 
- Lists and how to append to them
- Taking user input
- Basic Python syntax
